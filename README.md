# 후루룩찹찹 브랜드 사이트

한 그릇 전문점(덮밥·쌀국수·파스타·마라탕) 프랜차이즈 "후루룩찹찹"의 소개 웹페이지입니다.

## 파일 구조
- `index.html` — 전체 페이지 마크업
- `styles.css` — 전체 스타일 (프리미엄 에디토리얼 톤: 크림/브릭레드/골드, Noto Serif KR + Pretendard)
- `script.js` — 신메뉴 프로모션 팝업 동작 (24시간 숨기기 로직 포함, localStorage 사용)
- `assets/` — 로고, 마스코트, 메뉴 사진, 팝업 이미지

## 섹션 구성
01 브랜드 철학 → 02 브랜드 컨셉 → 03 시그니처 메뉴 3종 → 04 메뉴 아키텍처 표 →
05 전체 메뉴 갤러리(16종) → 06 타깃 고객 세그먼트 → 07 브랜드 지표 비교 →
08 입지·가맹 전략 → Q&A/문의 + 신메뉴("화산불백") 프로모션 팝업

## 로컬에서 확인하기
그냥 `index.html`을 브라우저로 열면 됩니다. (별도 서버 불필요)

## 참고
- 색상/폰트 등 디자인 토큰은 `styles.css` 상단 `:root` 변수에서 관리합니다.
- 메뉴 텍스트/가격 등 콘텐츠는 원본 사업제안서(브랜드 철학, 시그니처 메뉴, 타깃 분석, 지표 비교, 입지 전략) 내용을 기준으로 작성되었습니다.
